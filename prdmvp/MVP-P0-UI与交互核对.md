| 决策 / 场景 | 当前行为 | 实现 | 核验 |
|---|---|---|---|
| 页面范围、名称、权限 | 企业仅四页，默认API密钥；Developer限本人Key/用量 | V3App、mvp-policy、page-navigation | 路由与角色回归、浏览器导航 |

| 共同密度 | 标题27px、区块15px、表格11px；筛选38px，分页32px，行内动作中性色 | mvp.css、globals.css | 桌面与窄屏视图 |
| 四张主列表 | 默认5、选项5/10/20；筛选/改页数回第一页；空结果0–0、1/1；首末按钮禁用 | pagination、四个页面组件 | 边界单测及浏览器翻页 |
| 成员并发表头与列距 | 近 24h 并发峰值 / 成员并发上限；用户/角色20%、授权模型10%、并发31% | enterprise-mvp、mvp.css | 1440px桌面表头完整；授权模型左移约34px；390px页面无横向溢出，表格容器内滚动 |
| 搜索与重置 | 多条件交集；标题总量不变，结果独立计数；API/成员重置恢复输入焦点 | credentials-mvp、enterprise-mvp | 搜索空态与重置 |
| 停用Key | 行内容弱化，可用操作保持清晰；永久失效不提供恢复 | globals.css、credentials-mvp | 页面与状态回归 |
| 创建/启停Key | 有效输入才提交、完整密钥仅一次；确认失败保留弹层和错误 | credentials-mvp、mvp-pages | 表单禁用/取消、业务校验回归 |
| 邀请/编辑/移除 | 默认未选模型，选首个模型1路；超上限禁用；编辑无变化禁用；移除释放占位且原Key永久失效 | enterprise-mvp、member-lifecycle | 表单浏览器、生命周期/历史不变回归 |
| 页签与弹层 | 方向键循环、Home/End首末；Esc关闭、焦点恢复；模态背景隔离 | ui、modal-surface | 键盘与关闭回读 |
| 费用/用量 | 下钻携带账期、模型、用户；打印企业完整账期，CSV完整授权账期；分页不改变总额 | billing3-mvp、usage3-mvp | 浏览器下钻/账单预览，计量与导出单测 |
| 个人身份 | 个人首页参考现有C端，服务链接在新窗口打开platform.mosi.cn；不显示企业数据 | personal-page、V3App | 个人/企业切换及服务链接回读 |
| 无企业账号 | 正常成员关系才提供左下角切换；无关系只显示个人信息及C端个人页，不提供身份切换 | mvp-account、user-center | 正常/未加入/待接受/过期/移除/停用状态回归 |
| 常驻角色切换 | 企业/个人均保留右上角演示角色；URL保留角色和身份，刷新恢复；角色名不授予企业资格 | V3App | 个人视角切换Admin/Owner与刷新 |

业务差异按任务保留：企业资源展开两列、本人授权展开三列；费用/用量末页空行稳定表高，Key/成员自然行高；企业默认四页不限制C端自身导航。

## 验证结果与边界

已通过33项MVP回归、8项用量回归、28项页面契约检查、ESLint、TypeScript与Next生产构建。浏览器核对企业四页、个人页、共享分页、主要表单与确认层、资源展开、费用下钻、账单预览及窄屏布局。

企业原型继续使用本地演示数据，不代表真实短信、网关撤权、生产扣费或服务端鉴权已接入。个人服务由现有C端处理登录，原型不共享或伪造该站余额、密钥或会话。浏览器打印调用及CSV范围由代码与数据回归核验；不声称实体打印完成。

窄屏回读确认390px下无页面级横向溢出，四张主列表在容器内滚动；修正旧样式隐藏角色选择的问题。2026-09-10重新实测当前线上Admin（王开发）为正常企业成员：可访问企业四页；Developer编辑弹窗允许配置模型授权与并发上限，Owner及其他Admin无编辑入口；通过左下角用户信息卡片可在企业与个人身份之间切换，个人身份下仍保留Admin演示角色选择。浏览器未捕获应用错误。
