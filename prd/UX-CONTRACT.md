# 共用交互契约

更新：2026-09-11。业务权限及字段含义以[主PRD](./PRD-管理和组织模块.md)为准，视觉尺寸见[设计规范](./DESIGN.md)。

## 1. 导航与上下文

页签Tab进入选中项，左右方向键循环，Home/End到首末。移动侧栏由遮罩、Escape或选页关闭。左下角用户信息卡片打开身份菜单，点击外部或Escape关闭，Escape后恢复触发器焦点；是否提供身份切换按正常企业成员关系判断。

身份或角色切换清空搜索、筛选、页码、草稿、弹窗、下钻参数及旧请求/下载上下文。企业顶栏重置演示数据位于角色选择左侧，展开确认后才重置；取消或Escape不改数据。个人身份隐藏重置，演示角色选择保留。

## 2. 列表与筛选

四张主列表默认5条，可选5/10/20，统一显示“显示X–Y，共N条”、每页条数、上一页、当前/总页、下一页。空结果为0–0、1/1；首末和空页按钮禁用。搜索、筛选及每页数变化回第一页，数据缩减后校正页码。

重置筛选仅非默认条件时出现，紧邻末个条件；恢复默认条件和第一页，保留每页条数。搜索清空及搜索页重置后恢复输入焦点。密钥/成员标题总数不随筛选变化，结果数另示；账务合计取筛选全量，不取当前页。四张主列表筛选无结果时，空态区域均提供重置入口；API密钥与成员列表重置后恢复搜索焦点。

费用/用量末页用隐藏占位行稳定表格高度，密钥/成员按自然内容高度。密钥/成员宽表在容器内横向滚动；费用/用量表窄屏转为纵向记录，禁止裁掉字段或数值。详情Key表展示全部掩码记录，不套主列表分页。

费用中心表格按查看对象安排首列：用户用量概览为“用户 → 模型”，API Key 用量明细为“API Key → 所属用户 → 模型”，窄屏纵向记录保持相同字段顺序。筛选器顺序保持账期、模型、用户、API Key（仅明细页），不决定表格列序；两表均在副说明中明确按模型分行。

## 3. 弹窗与表单

创建、邀请、编辑和详情使用dialog，移除和Key启停使用alertdialog。背景不可操作，焦点限制在顶层弹窗；Escape关闭并恢复原触发器焦点，长内容只有一个主滚动区。表单初始焦点进入首字段，危险确认默认聚焦取消。

标签关联输入，隐藏标签使用sr-only。必填项缺失、字段非法、编辑无变化或请求提交中禁用主按钮；成员上限是可空字段，留空不属于校验失败。失败保留草稿与弹窗，成功提交才关闭；取消不改数据。

邀请与编辑使用两列模型卡，第一行勾选框、模型名、企业并发上限和类型，第二行成员上限输入与单位。勾选后默认留空且提示“不限制”；取消勾选清空并禁用，重新勾选仍留空。邀请至少选择一个模型，编辑可取消全部；显式填写须为1至企业上限的整数。

不显示“选填”“最多N路”或顶部解释段。超企业上限时仅将企业上限文字与输入边框同色标红，禁用保存，不增加错误行或改变卡片高度；其他非法数字仅输入框标红。错误文本通过aria-describedby与读屏提示关联，不能只靠颜色传达校验失败。

详情进入编辑或移除保持同一对象和权限；取消编辑返回用户列表。创建Key成功即入列，关闭成功态不回滚；Secret只展示一次，复制反馈取真实剪贴板结果。

## 4. 摘要、加载与反馈

资源摘要展开整行可点，支持Enter/Space、aria-expanded及加减号；展开后保留接近/已达上限数量，零数量及分隔点隐藏。无额外只读角标。状态以文字和颜色共同表达；停用Key中性弱化，可用启用操作仍清晰。

加载、网络失败、未覆盖与真实零分别表达；提交中禁用重复操作。版本冲突保持失败并提示刷新，关系失效阻止旧上下文访问。详细数据口径及阈值见主PRD7.7。

## 5. 打印、下载与响应式

费用页先打开账单预览，再由预览按钮调用浏览器打印；取消浏览器打印保留预览，关闭预览恢复原页筛选、页码和入口焦点。不能以打印对话框结束宣称打印/PDF保存成功。完整范围和按钮状态见主PRD7.4.1，CSV规则见7.5。

窄屏控件整体换行，分页和按钮不竖排；模型卡620px及以下单列。打印只输出账单内容，不输出隐藏页面占位或导航。按主PRD AC-13–16核对分页、键盘、焦点、窄屏和重置，其余业务验收使用对应AC编号。
