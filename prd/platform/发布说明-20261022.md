# 发布说明｜2026-10-22

当前功能基线 1d174a5（2026-10-22）。本次仅补齐企业阶梯模型账单的三档展示及对应检查，未改变其他页面、样式、计费逻辑、历史快照与 CSV。52 项平台业务检查、账单专项、账本一致性、ESLint 和 TypeScript 均通过，生产构建成功；Vercel production READY。线上固定范围 2026-10-14 至 2026-10-20、moss-transcribe 与 kimi-k3、全部 Key：874 次、5,625.79 积分、¥281.29，预览与打印一致，打印内容自动分为 2 页。不同浏览器已有 mock 账本的数值可能不同，应核对同一账本的前后合计。

浏览器打印 A4 横向，仅输出正文。按纸张宽度实测内容高度，以完整模型组分页；补齐三档后行数增加，页数可随内容自然增加。放得下则一页，放不下自然分页，不为凑一页缩字号或改变模板。续页保留 MOSS API、账期、表头、“计费明细（续）”；页末模型无多余底线，页脚含生成时间与页码。
