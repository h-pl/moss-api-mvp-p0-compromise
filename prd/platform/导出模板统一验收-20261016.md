## 当前统一规则

| 检查项 | 账单预览 | 打印账单 | 导出明细 |
| --- | --- | --- | --- |
| 标题、汇总、表格、合计 | 共用文档组件与样式 | 同模板按纸张比例排版 | 同模板；保留明细专属列 |
| 模型范围 | 不重复显示 | 不重复显示 | 不重复显示 |
| 全部 Key / 逐项选满 | 隐藏摘要 | 隐藏摘要 | 隐藏摘要 |
| 部分 Key | 标题右侧单行，名称省略、共 N 个 | 每页同样单行、总数完整 | 两种导出方式一致 |
| 摘要宽度 | 460 模板单位，上限 70% | 相同比例 | 相同比例 |
| 生成时间 | 保留 | 保留，带页码 | 正文不显示，实际下载时间进入 CSV 文件名 |
| 导出方式标题 / 绿色成功提示 | 不适用 | 不适用 | 均不显示；保留两种选项、重下载按钮与错误提示 |

上述差异为已确认的业务差异，不是模板不同步。明细首项为导出记录、第二列为 API Key；账单首项为计费模型、第二列为计费规则。

## 实际验证

- 企业本月全部 Key、近七天单 Key、本月 25 个 Key、近七天逐项选满：逐项比较预览与打印的所有明细行、统计周期、汇总、合计、Key 摘要和字体/字号/行高比例，全部一致。
- 同四种场景比较汇总明细和账单：统计周期、请求次数、积分、金额、合计及公共样式一致；切换逐请求后摘要保持一致。
- 个人空间：账单、打印、汇总明细、逐请求入口正常，个人数据隔离，合计一致。
- 仅选无历史请求的 mock Key：账单和明细导出按钮均禁用。
- 390px 窄屏：摘要保持单行，总数完整，文档无横向溢出。
- 实际生成“本月全部 Key”“本月 25 个 Key”两份 A4 横向 PDF，共四页；Poppler 渲染后逐页查看，续页摘要、页码和末页合计正常，无遮挡、截断或额外空白页。
- 实际下载近七天两种 CSV：模型-Key 汇总 12 条、逐请求 1471 条；两份合计均为 1520.50 积分、76.03 元，与页面一致。文件名时间与实际点击下载时间一致，使用 UTC+8；下载后无旧生成时间或绿色提示。
- ESLint、TypeScript、52 项平台业务检查、账单回归、持久化账本回归通过。

PDF 数字采用字体字形映射，本轮数值比较使用打印 DOM 和实际渲染，不把纯文本提取结果作为数字核验依据。
