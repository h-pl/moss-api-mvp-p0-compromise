# Mock 数据一致性核对（2026-10-17）

核对对象：本地 4002，企业与个人空间、Key 列表、用量/请求明细、账单预览与打印数据、两种 CSV、价格页、余额与充值弹窗。代码检查与业务回归通过不代表下列尚未修复的问题已通过验收。

## 本轮已修复

新增 30 个企业 Key 原先仅存在于列表，生成请求时被排除。账本 v6 将已有企业 fixture 请求按稳定规则分配到新增 Key，保留请求 ID、用量、结算快照和金额；按创建时间与模型授权选择接收 Key。旧 Key 保留部分请求，个人请求不变。刷新幂等，用户修改的 Key 名称、启停/删除和备注保留，仅替换旧的“模拟业务 Key，暂无历史请求”默认备注。

实际本地缓存近 7 天（10 月 10–16 日）：35 个企业 Key 有计费用量，模型-Key 汇总 208 行，请求明细 1,430 行；账单与两种 CSV 均为 1,513.35 积分 / 75.6675 元（页面 75.67 元）。单独筛选新增 Key 可得到对应 7 个模型明细。Key 列表数量不要求与有用量的 Key 数量相等，没有请求的 Key 不生成虚假明细。
