# MVP-P0 变更影响清单

同步基线：2026-09-09 [研发主 PRD](./PRD-管理和组织模块.md)与[飞书研发文档](https://acnc6zeentra.feishu.cn/wiki/GfJQwQLMFiabOOktdUNcaAxsnRd)。本文细化对应章节的研发要求，截图为线上演示快照；生产数据及权限以服务端为准。

以下按当前业务触发列出跨页联动，用于研发回归。

| 触发 | 可见结果 | 不变量 / 验证 |
|---|---|---|
| 企业工作区导航 | API密钥、费用概览、用量明细、企业与用户 | 默认API密钥，Developer仅本人Key及用量；个人页入口按成员资格显示 |
| 页面定位 | 侧栏、页签、H1、浏览器标题一致 | 正式名称与主PRD页面地图一致 |
| 移除资源只读角标 | 两处摘要仅区标题 | 只读数据和授权规则不变 |
| 统一列表 | 四页共享5/10/20、默认5、文字翻页 | 空/首/末页禁用，条件变化回1，账务合计不随分页 |
| 成员授权/并发变更 | 企业列表、详情、本人资源同步 | 校验单项企业上限，成员上限之和可超过企业上限；不预留并发，历史峰值不变 |
| 移除成员 | 列表及席位占用消失，原企业Key永久失效；按生效规则回收并发额度 | 个人Key、历史费用用量不变 |
| 同手机号再邀请 | 新关系、新授权，需新建Key | 原Key不可启用，稳定账务身份保留 |
| Key创建/启停 | 本人列表和资源摘要更新 | 只操作本人，校验失败不关闭确认层 |
| 费用下钻 | 带账期/模型/用户到用量 | Key=全部、窗口=整账期，重验权限 |
| 角色或身份切换 | 按成员资格和权限进入企业页或个人页 | 清空旧筛选、页码、草稿、弹窗、请求结果和下载上下文 |
| 用户中心 | 有企业账号可切换C 端个人页；无企业账号无切换入口 | 个人页不显示企业数据 |
| 打印/导出 | 完整企业/授权账期 | 不受临时筛选或分页缩小；Developer仍限本人 |

实现与验证证据见[UI与交互核对](../../prdmvp/MVP-P0-UI与交互核对.md)。生产业务记录包含操作者、对象、动作、必要前后状态与结果，并对敏感字段脱敏。

右上角演示角色切换在企业和个人身份下始终保留，不受企业账号资格影响；角色不等于企业成员关系，企业账号资格以当前成员状态为准。

个人页采用[现有 C 端](https://platform.mosi.cn/)的信息架构，服务新窗口打开并使用个人登录；企业与个人数据分别维护。
