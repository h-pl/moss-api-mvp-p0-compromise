# MVP-P0 UX 契约

同步基线：2026-09-09 [研发主 PRD](./PRD-管理和组织模块.md)与[飞书研发文档](https://acnc6zeentra.feishu.cn/wiki/GfJQwQLMFiabOOktdUNcaAxsnRd)。本文细化对应章节的研发要求，截图为线上演示快照；生产数据及权限以服务端为准。

对应主 PRD 7.1、7.2及各页交互。企业四页统一导航、标题、列表、弹窗与反馈；费用和用量保持各自业务粒度。

## 1. 导航与身份

接入管理 → API 密钥；费用中心 → 费用概览/用量明细；企业管理 → 企业与用户。默认 keys，页面范围见[范围文档](../../prdmvp/MVP-P0页面范围.md)。侧栏选中态与当前子页一致，Developer只有接入管理和费用中心入口。

页签支持鼠标、Tab进入选中项、左右方向键循环、Home/End跳首末。移动端侧栏打开后可由遮罩、Escape或选页关闭。点击左下角用户信息卡片打开用户中心，在“切换身份”中选择“企业”或“个人”。用户中心保留当前身份资料，点击外部或Escape关闭并在Escape后恢复触发器焦点；有企业账号可切换至C 端个人页，隐藏企业内容；无企业账号不提供切换入口。身份或角色变化清空搜索、筛选、页码、草稿、弹窗、旧请求结果及下载上下文；演示身份参数随刷新恢复，生产会话和缓存按身份隔离。

企业身份下，“重置演示数据”位于顶栏演示角色选择的左侧，侧栏底部仅保留身份卡。重置先展开确认，取消或Escape不改变数据；确认区域在窄屏内显示，不挤占角色选择。

受邀用户从短信进入时，登录页默认预填受邀手机号并使用验证码登录；未注册账号在验证成功、同意协议并点击登录后自动创建。已有账号登录或已有会话均须校验手机号与邀请一致。服务端自动接受成功后，提示已加入企业并刷新左下角用户信息卡片的企业选项；用户按需切换身份。错误账号引导切换登录账号，过期/撤销提示联系Owner或Admin，重复打开有效成员已接受的邀请保持幂等。详见主PRD7.6.4；当前原型尚未接入此真实链路。

## 2. 列表与筛选

四张主列表统一Pagination：默认5条，可选5/10/20；左侧“显示 X–Y，共 N 条”，右侧“每页”、上一页、当前页/总页、下一页。空结果显示0–0、1/1，两侧禁用；首末页按边界禁用。条件及每页数变化回第一页，数据缩减时页码不越界。

搜索即筛选，清空搜索和重置搜索页恢复输入焦点。重置仅在条件变化时出现，紧邻末个条件，恢复默认筛选和第一页但保留每页条数；当前API密钥空结果使用筛选栏的“重置筛选”，其余主列表在空态内也提供该入口；此差异记录在主PRD文末Q-01。密钥和成员标题总数不随筛选变化，筛选结果数另示；费用与用量合计覆盖当前筛选全量，不随页码变化。

费用/用量末页用隐藏占位行保持高度，成员/密钥自然内容高度；差异用于图表下方长表稳定，不改变分页语义。所有表在窄屏内部横向滚动，不推动整页横向溢出。

成员列表列宽：用户/角色20%、授权模型10%、并发31%、API Key13%、账号状态10%、操作16%。授权模型列靠近用户/角色；并发表头为“近 24h 并发峰值 / 成员并发上限”，表头与内容左对齐，窄屏保持表格容器内横向滚动。

## 3. 资源摘要与状态

企业资源池和我的调用资源均无只读角标。展开入口整行可点且支持Enter/Space、aria-expanded、+ / −；展开后保留接近/已达数量。颜色含义全站统一：正常绿，停用中性，接近上限橙，已达上限红；未知不是0。停用Key整行弱化，启用按钮保持正常可见。

## 4. 创建、编辑及确认

创建/邀请/编辑使用ModalSurface dialog，移除与Key启停使用alertdialog。系统顶层dialog阻止背景操作，只有一个内部滚动区；Escape关闭，关闭热区至少44px；关闭后恢复原触发器焦点。

表单默认焦点进入首字段；手机号/名称/角色/授权/并发校验未通过或编辑无变化时主按钮灰色禁用，数据有效后为近黑色。错误留在表单并保留草稿。含字段表单规则见[通用表单](./规范-通用表单设计.md)。

无输入确认层默认聚焦取消；停用和移除为危险色，启用为近黑。操作失败保留确认层并显示错误，成功才关闭。取消不改变数据。创建Key成功立即入列，关闭成功态不回滚；secret只展示一次，复制反馈不改变授权。

详情→编辑/移除保持同一对象，动作权限一致。Owner不可移除，Admin只操作Developer。邀请/编辑统一使用两列模型卡：首行“模型名 · 企业并发上限 X 路”，次行“成员上限”输入和单位“路”。勾选后默认留空，提示“不限制”；取消勾选清空并禁用，保存为未授权。邀请至少选择一个模型，编辑可取消全部。填写时只允许1至企业上限的整数，无变化禁用保存。超限仅使企业上限文字与输入边框同色标红，不新增错误行或改变卡片高度；不显示“选填”“最多N路”或顶部解释文案。

## 5. 费用和用量

默认本人、当前账期、全部模型；用量默认全部Key和整账期。费用查看明细携带账期、模型、用户进入用量，普通页签导航清除下钻参数。Developer切换不能带入他人上下文。

费用摘要顺序：折后金额估算→账期积分消耗→计费调用次数。费用ASR用小时，用量明细表/CSV用秒；图表用小时，单位始终明确。热力图点日仅变当天说明，不过滤表格。时间窗口无交集显示“—”及回整账期入口；有覆盖无调用显示真实0。

打印采用“页面按钮打开账单预览 → 预览按钮唤起浏览器打印”两步操作，按完整企业账期汇总到模型。关闭或 Esc 退出预览且保留筛选、页码并恢复入口焦点；取消浏览器打印后保留预览，可再次操作。浏览器负责打印机、PDF 保存及版式设置，页面不能据对话框结束宣称打印或保存成功。打印不得因页面隐藏内容占位产生多余空白页。导出完整授权账期到 Key，不因当前筛选为空被禁用；打印和导出范围均不受分页影响，不表示结算或发送账单。详细按钮规则见主 PRD 7.4.1。

## 6. 视觉及响应式

表头10–11px，主列表正文/分页/行内操作11px，辅助文字10px，区标题15px、总数11px；筛选输入12px高38px。焦点使用中性深灰 #596168 内描边，复合搜索框只显示一次。重置和行内动作无下划线；趋势图保留橙色，仅用于数据表达。

窄屏完整控件换行，页码按钮及“每页+条数”不得竖排；邀请与编辑模型卡宽屏为两列，620px及以下为单列。细节见[设计规范](./DESIGN.md)。

右上角演示角色切换在企业和个人身份下始终保留，不受企业账号资格影响；角色不等于企业成员关系，企业账号资格以当前成员状态为准。

个人页采用[现有C端](https://platform.mosi.cn/)的信息架构，服务在新窗口打开并使用个人登录；企业与个人数据分别维护。

## 7. 反馈与验收

加载不先显示真实零；网络失败保留输入并允许重试，写入失败不提示成功。版本冲突提示刷新，权限或成员关系失效阻止继续使用旧上下文。提交期间禁用重复操作，下载生成和获取均重验授权。

主 PRD AC-01、AC-02、AC-08–16为跨页验收入口；[截图清单](./assets/20260909/README.md)覆盖页面、创建、邀请、详情、移除和打印。数据快照变化只更新数值，不改变页面结构、范围语义和交互规则。

并发总分配包含Owner、Admin、Developer及有效待接受邀请；闲置和停用Key不自动回收，接受不重复占用，过期/移除按生效规则释放。详见主PRD7.7.1；Q-06记录原型仍待改造的差异。
