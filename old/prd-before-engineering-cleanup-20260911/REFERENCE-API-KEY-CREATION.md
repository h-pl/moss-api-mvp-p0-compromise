# API Key 创建交互参考（MVP-P0）

同步基线：2026-09-09 [研发主 PRD](./PRD-管理和组织模块.md)与[飞书研发文档](https://acnc6zeentra.feishu.cn/wiki/GfJQwQLMFiabOOktdUNcaAxsnRd)。本文细化对应章节的研发要求，截图为线上演示快照；生产数据及权限以服务端为准。

企业规则以主 PRD 7.3 为准；现行入口为 [API 密钥](https://moss-api-enterprise-console.vercel.app/?view=keys)。本文记录已采用的创建交互及验收，不扩展交付范围。

## 创建条件和输入

创建按钮始终位于页头；成员正常、至少一个模型授权、当前关系Key少于50个时可用，否则禁用并提示原因。普通停用Key占额度，永久失效历史Key不占额度。创建前由服务端重新校验条件和本人归属。

弹窗只有名称可编辑，去首尾空格后1–50字，显示字符计数；空白名称禁用确认。授权模型为只读继承说明及当前模型数量，各Key共享成员模型策略和并发上限。

## 提交、成功与关闭

有效提交后创建Key并立即加入本人列表；失败保留名称与错误原因。成功态只展示一次完整Secret，提供复制和“我已安全保存”。关闭或刷新后列表仅显示掩码，关闭不撤销创建；复制失败提示重试，不改变授权或Key状态。

生产Secret由服务端签发，不进入列表、日志、埋点或持久缓存；sk_demo_仅为原型演示。创建请求应幂等，并原子校验数量，避免并发创建突破额度。

## 验收与引用

按主 PRD AC-03、AC-04、AC-14验收。重点核对全空格和50字边界、额度49/50、无模型、成员失效、重复提交、复制失败、关闭后焦点恢复及完整Secret不可重新查询。
