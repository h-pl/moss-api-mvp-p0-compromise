# 接入管理正式页面实现说明（MVP-P0）

同步基线：2026-09-09 [研发主 PRD](./PRD-管理和组织模块.md)与[飞书研发文档](https://acnc6zeentra.feishu.cn/wiki/GfJQwQLMFiabOOktdUNcaAxsnRd)。本文细化对应章节的研发要求，截图为线上演示快照；生产数据及权限以服务端为准。

对应主 PRD 7.3；文件名用于保持既有文档链接。

唯一页签为 [API 密钥](https://moss-api-enterprise-console.vercel.app/?view=keys)，组件为 `app/v3/credentials-mvp.tsx` 的 `ApiCredentialsMvp`。正常企业成员中的Owner/Admin/Developer仅管理本人企业Key。

## 我的调用资源

四项摘要依次为模型授权→我的 API Key→本人本月已用积分→企业积分余量。删除“账号策略 · 只读”角标，与企业资源池一致。模型摘要已授权/全部模型数及TTS/ASR数；Key摘要当前关系总数/50，普通停用计入、永久失效不计创建额度；余额来自独立企业快照。

展开本人授权模型，三列：模型、近24h并发峰值/本人并发上限、本月已用积分。复用capacityLimitState，80%至不足100%接近、100%起已达，互斥且零数量隐藏；未知值不计预警。展开后保留计数、+变−，底部仅数据更新时间。

## Key列表及操作

仅本人企业Key，六列：API Key、创建时间、本月已用积分、最近调用、状态、操作。标题总数稳定；搜索/状态筛选交集，条件变化回第一页。Pagination共享5/10/20、默认5、文字翻页、空态0–0。停用中性状态匹配整行弱化样式，可启用按钮保持近黑。空结果显示标题与提示，重置筛选位于筛选栏；其余主列表空态另有重置入口，此差异见主PRD文末Q-01。

创建名称1–50字、只读继承授权模型；成员正常、有有效授权且现存Key未达50才允许。创建成功立即提交快照，一次展示Secret，复制按真实结果反馈，关闭不回滚。启停使用共享alertdialog；取消默认焦点、确认失败保持弹窗并显示错误，成功才关闭。永久失效不允许启用。生产Secret不进入列表、日志、埋点或持久缓存。

## 共享状态与生产边界

mvp-pages.tsx和validateMvpKey保证当前快照校验，演示存储moss-api-shared-enterprise-demo-v2与企业/账务同源。生产Key签发、网关即时生效、幂等、必要业务记录与可信计量仍需后端接入。

## 边界与验收

创建按钮保留在页头。达到50个、成员状态不可用或无模型授权时禁用，并提供对应原因；名称去首尾空格后1–50字。普通停用Key占额度，成员移除造成的永久失效历史Key不占额度。创建、启用和停用均按当前快照重验本人所有权及状态。

按主 PRD AC-03、AC-04、AC-07、AC-13、AC-14核对创建成功只展示一次Secret、关闭不回滚、复制失败反馈、状态冲突保持错误、容量未知与真实零的区别、分页和焦点。源码见[Key生命周期](./diagrams/02-key-lifecycle.mmd)，完整字段契约见主 PRD 7.10。
