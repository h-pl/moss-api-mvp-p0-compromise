# MVP-P0 设计规范

同步基线：2026-09-09 [研发主 PRD](./PRD-管理和组织模块.md)与[飞书研发文档](https://acnc6zeentra.feishu.cn/wiki/GfJQwQLMFiabOOktdUNcaAxsnRd)。本文细化对应章节的研发要求，截图为线上演示快照；生产数据及权限以服务端为准。

对应主 PRD 7.2。运行时来源为 `app/globals.css` 与 `app/v3/mvp.css`，约束企业四页、个人入口及其弹窗。

## 色彩与语义

| 用途 | 值 / 规则 |
|---|---|
| 主文字 / 主按钮 | #171717 |
| 次要文字 | #727272 |
| 页面背景 / 面板 | #F6F7F8 / #FFFFFF |
| 表格整行hover | #FCFCFC，整行统一，不覆盖选中或业务状态 |
| 常规描边 | #E5E7E9 |
| 用量图表 | #F4772E，仅用于趋势和热力图 |
| 成功 / 预警 / 危险 | #16864A / #B96019 / #B8323A |
| 焦点 | #596168 边框，inset 0 0 0 1px rgb(23 23 23 / 12%) |
| 禁用提交 / 停用内容 | #9B9B9B / #B7B7B7 |

停用 Key 用中性状态，不用危险红；文字及图标整体弱化，但可用的启用动作保持近黑。移除和停用的确认按钮使用危险色。无效表单主按钮灰色，满足条件后近黑。重置和行内动作无下划线，焦点使用统一中性边框。

## 字体与密度

| 元素 | 规格 |
|---|---|
| 页面标题 / 描述 | 27px / 12px，沿用统一PageHeader |
| 区标题 / 数量 | 15px / 11px |
| 筛选输入与下拉 | 12px，高38px，圆角7px |
| 表头 / 正文 / 辅助文字 | 10–11px / 11px / 10px |
| 对象名称 / 行内动作 | 12px / 11px |
| 分页 | 11px，按钮/下拉高32px，完整文字上一页/下一页 |
| 邀请编辑标题 / 字段 | 22px；字段标签11px、输入13px、高48px |
| Key紧凑创建标题 / 字段 | 22px；名称输入13px、高40px |

表单正文长度不同可使用紧凑Key弹窗和较宽成员编辑弹窗；不机械强制同宽。所有关闭按钮热区至少44px。金额与用量使用tabular-nums，数值右对齐、单位明确，不被折行为逐字竖排。

## 面板与布局

统一浅灰画布、白色圆角面板、侧栏与顶部品牌。API密钥和企业与用户采用资源摘要+列表两段式。两处资源头均不显示额外只读角标。

费用的金额摘要字重700，其余摘要500；费用/用量图表橙色、白色提示层、浅灰网格。业务差异保留：费用按模型×用户，用量按模型×用户×Key；图表本身不要求复制资源摘要布局。

## Forms

复合搜索框仅外层显示焦点，不叠加内部input描边。重置筛选紧邻最后一个条件，仅非默认态出现。共享Pagination默认5条、5/10/20选项，计数、文字按钮和边界禁用一致。

邀请编辑表单、Key创建、移除和启停确认遵循[通用表单规范](./规范-通用表单设计.md)，字段区与操作区不额外增加装饰分割线。

## 响应式与打印

窄屏侧栏为抽屉；筛选整控件换行、分页分行但按钮不压缩竖排。邀请与编辑模型卡宽屏为两列，620px及以下为单列，模型名与企业并发上限文案在窄屏自然换行。密钥/企业模型表内部横向滚动，不使body溢出；用户用量概览和API Key用量明细采用纵向响应式布局，不出现横向滚动条。

用户用量概览与API Key用量明细均自适应容器、无固定最小表宽；容器760px及以下改为带字段名的纵向记录，完整保留字段、合计、分页及操作，两表不出现横向滚动条。表格左右外缘、标题和分页统一24px留白，窄屏为16px；内侧列保持10px。账单预览可以更宽，打印只输出账单内容，不输出侧栏或按钮。所有弹层最多一个主滚动容器。

## 页面证据与验收

页面名称及在线入口由[主 PRD 页面地图](./PRD-管理和组织模块.md#31-页面地图与线上入口)统一维护；逐页截图见[截图清单](./assets/20260909/README.md)。实际截图作为视觉基线，演示人数、日期、余额不作为固定设计值。

顶栏在企业与个人身份下保留演示角色选择；企业身份的重置演示数据位于其左侧。左下角只对正常企业成员提供企业/个人切换，无企业账号仅展示个人身份信息。个人页使用C端信息架构，服务新窗口打开。

按主 PRD AC-13–16核对默认5条、5/10/20选项、弹窗焦点、窄屏及重置；使用文本和颜色共同表达状态。加载、失败、未覆盖与真实零保持可区分。
