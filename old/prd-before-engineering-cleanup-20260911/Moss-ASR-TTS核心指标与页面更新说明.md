# Moss ASR / TTS 核心指标与页面更新说明

同步基线：2026-09-09 [研发主 PRD](./PRD-管理和组织模块.md)与[飞书研发文档](https://acnc6zeentra.feishu.cn/wiki/GfJQwQLMFiabOOktdUNcaAxsnRd)。本文细化对应章节的研发要求，截图为线上演示快照；生产数据及权限以服务端为准。

对应主 PRD 7.7、7.8；费用与用量细则见[费用中心 PRD](./PRD-费用中心.md)。

## 页面职责

费用中心采用 [费用概览](https://moss-api-enterprise-console.vercel.app/?view=billing3) 和 [用量明细](https://moss-api-enterprise-console.vercel.app/?view=usage3)，显示为费用概览、用量明细。费用概览按模型×用户汇总；用量明细按模型×用户×API Key 汇总。Owner/Admin 可查看费用及企业范围用量；Developer 只能查看本人用量。费用页“查看明细”传递账期、模型、用户，Key 重置为全部、窗口重置整账期。

打印仅在费用概览，按企业完整账期聚合到模型并展示计费规则；导出仅在用量明细，按完整授权账期导出 Key 级 CSV。两者不受页面临时筛选及分页影响。六模型费率、逐条计量舍入、单位、空态和表格规格统一见 [费用中心 PRD](./PRD-费用中心.md)。

## 核心指标

计费调用次数为有效计量的逻辑调用去重次数；TTS 为计费字符，ASR 为计费音频长度。积分为账本消耗，人民币为企业生效换算下的估算。当前企业余额是独立权益快照，只在费用概览和资源相关页面展示。费用概览与用量图表的 ASR 使用小时，用量表/CSV 使用秒；单位分开，显示精度不改变计量底账。

费用概览摘要顺序为“折后金额估算 → 账期积分消耗 → 计费调用次数”，窄屏阅读顺序一致。金额数值字重700，其余两项500，保留“估算”标签；筛选后保持指标定义、同一快照和阅读顺序一致。

## 企业资源与 API 密钥

近24h并发峰值来自真实占用/释放时序，企业峰值取各时刻所有用户并发总数的最大值，不等于各用户独立峰值之和，也不能从调用次数推算。页面将近24h峰值与当前同范围并发上限比较：低于80%中性、80%至不足100%橙色、100%起红色。上限变更更新分母、状态和筛选，历史峰值及发生时间不变。缺失/未覆盖/非正上限显示暂无完整数据，不能按0%判为充足。Key没有独立配额层。页面仅显示简短更新时间，完整口径保留在PRD。

## 验收

比较相同可信范围和完整账期的卡片、图表、表格、模型账单及Key级CSV；余额与筛选无关。校验单位换算、规则版本、逐条舍入、授权隔离及空态。原型fixture只用于前端验证，真实账号、计量、账务、历史权益和下载权限仍需服务端联调。

共用控件见[UX契约](./UX-CONTRACT.md)与[设计规范](./DESIGN.md)。

## 接口字段和边界

资源返回scope、model、window_start/end、peak、peak_at、current_limit、coverage、data_as_of；相同峰值取最近发生时间。并发为企业和成员两层同时约束，多个Key共享成员上限，成员配置之和不是企业独占预留。

计量返回稳定企业/用户/Key标识、账期、数据快照、逻辑调用去重数、billable quantity、单位、生效规则版本、消耗积分与金额。TTS字符、ASR秒/小时可以换算；舍入在最小计量记录上执行，不能从展示值反算价格。

原型参考换算率0.03元/积分及六模型规则用于演示，生产采用企业生效协议。无覆盖、非有限或负峰值、非正上限为未知；真实覆盖且峰值0才展示0。验收覆盖79.9%、80%、99.9%、100%和上限变更，对应主PRD AC-07、AC-10、AC-11。
