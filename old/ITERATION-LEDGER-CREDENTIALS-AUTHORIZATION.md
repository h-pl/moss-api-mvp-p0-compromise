## 最终结论

- API 凭证选定候选7并提升为唯一正式 `?view=keys`；音色授权选定原候选6并保持唯一正式 `?view=voices`。
- API 凭证原版、候选5、6、8和所有数字后缀页签已从运行代码移除；历史地址统一归一到正式入口。
- 正式 API 凭证的角色差异集中在本人配额、积分用量、模型与本人 Key；正式音色授权只展示当前企业权益。该结论只说明原型逻辑可运行，不代表后端鉴权、计量和合同权益已接入。
