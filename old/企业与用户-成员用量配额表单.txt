企业与用户｜成员用量与配额表单


一、页面定位

页面名称：企业与用户
页面说明：Owner 创建和管理企业成员，并为成员分配积分、ASR、TTS 额度和调用限流。
资源归属：企业积分池 → 成员账号 → API Key
说明：不使用 Project 概念；提醒策略不放在邀请或编辑成员弹窗中。


二、页面顶部统计卡片

1. 企业账号
   主值：4
   辅助说明：1 位 Owner · 3 位成员

2. 企业积分余额
   主值：90,000 积分
   辅助说明：已购买 100,000 积分 · 已使用 10,000 积分

3. 本周期已用
   主值：10,000 积分
   辅助说明：按 TTS、ASR 和其他模型调用统一扣减

4. 待接受邀请
   主值：0
   辅助说明：成员接受邀请后，分配额度正式生效


三、成员用量与配额表格

表格标题：成员用量与配额
右上角辅助信息：Owner + 3 成员

字段顺序：

账号 | 角色 | 积分 | ASR | TTS | RPM | 并发 | API Key | 状态 / 操作


四、表格字段定义

1. 账号
   第一行：成员姓名
   第二行：手机号（脱敏）
   可选第三行：账号 ID
   示例：
   王开发
   139****1234
   acct_1001

2. 角色
   可选值：
   Owner
   Admin
   Developer
   Finance
   Viewer

3. 积分
   展示格式：已用 / 分配
   示例：8,420 / 20,000 积分
   辅助信息：剩余 11,580 积分
   Owner 可展示：企业共享池

4. ASR
   含义：语音转文字的音频用量
   展示格式：已用 / 配额
   示例：6.2h / 20h
   辅助信息：剩余 13.8h
   无 ASR 配额时显示：不限或 —

5. TTS
   含义：文字转语音的字符用量
   展示格式：已用 / 配额
   示例：180,000 / 500,000 字符
   辅助信息：剩余 320,000 字符
   无 TTS 配额时显示：不限或 —

6. RPM
   含义：每分钟最大请求数
   展示格式：当前值 / 上限，或仅展示上限
   示例：42 / 100
   辅助信息：当前窗口

7. 并发
   含义：同时执行的最大请求数
   展示格式：当前值 / 上限
   示例：5 / 20 路
   辅助信息：请求结束后释放

8. API Key
   展示格式：有效 Key 数量
   示例：2 个
   Owner / Admin：全部管理
   普通成员：可管理 0 个 / 1 个 / 2 个 Key

9. 状态 / 操作
   状态值：
   正常
   接近上限
   已停用
   待接受
   已过期

   操作值：
   查看账号
   调整资源
   编辑成员
   停用账号
   恢复账号

六、邀请 / 编辑成员弹窗

弹窗标题：邀请并分配成员
副标题：为成员设置角色、积分和调用资源上限。


【基础信息】

手机号
控件：单行输入框
占位：请输入 11 位手机号
必填：是
说明：邀请链接绑定手机号；不再收集或展示企业邮箱。已注册用户点击链接直接受邀，未注册用户进入手机号预填的登录页获取验证码后受邀。

角色
控件：下拉选择
可选值：Admin / Developer / Finance / Viewer
说明：Owner 不通过普通邀请流程创建。


【积分分配】

企业积分池可用：87,520 积分

成员积分上限
控件：数字输入框
单位：积分
示例：10,000
必填：是

【服务配额】

ASR 音频配额
控件：数字输入框
单位：小时
示例：20
可选：不限

TTS 字符配额
控件：数字输入框
单位：字符
示例：500,000
可选：不限

说明：ASR、TTS 是用量配额；实际扣费按照计费标准折算为积分。


【调用限流】

RPM
控件：数字输入框
单位：请求 / 分钟
示例：100
必填：是

并发
控件：数字输入框
单位：路
示例：20
必填：是

说明：TPM 不作为本表单字段。当前产品的主要模型按 TTS 字符和 ASR 音频时长计费；如果后续接入 Token 型模型，再增加 TPM 字段。
底部按钮：

[取消] [发送邀请]


七、表单校验规则

1. 企业邮箱、角色、积分上限、RPM、并发为必填项。
2. 积分上限不能超过企业积分池当前可分配余额。
3. ASR、TTS 配额可以设置为“不限”。
4. RPM 和并发必须为大于等于 0 的整数。
5. 企业邮箱不能重复邀请已有成员。
6. Owner 不允许通过普通邀请创建第二个 Owner。
7. API Key 权限由角色自动继承，不提供单独编辑字段。
8. 邀请弹窗不展示提醒策略和生效预览。
