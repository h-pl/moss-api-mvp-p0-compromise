# Moss API Customer Control Plane V3

当前原型版本：`3.0.0-beta.8`

以 V2 完整客户控制台为产品基线、移除内部运营台，并加深企业交付信息查询能力的 V3 原型。当前版本已保留模型发现、体验、开发、费用、企业管理和专属服务，并补齐：

- 项目凭证：项目、API Key、团队权限、账号安全、配额与限流
- 费用中心：费用概览、订单权益、用量与对账
- 调用日志：请求诊断、合同服务质量及日/周/月维度查询
- 企业治理：成员邀请、角色、项目范围、菜单与页面级权限、操作审计
- 调用归因：Workspace → Project → API Key → request_id → MeterEvent

## 当前可演示链路

- Owner/Admin 邀请成员，分别配置角色、Project Scope 与按项目的 `credential.manage`；可切到受邀成员完成接受与 MFA，停用、恢复和撤回均形成可见状态
- 顶部角色任务条支持 Owner、Admin、Developer、Finance、Viewer 五种高保真任务视角，导航和数据范围随角色同步变化
- 企业身份与 Workspace 统一在左下角展示，顶栏不再重复账号入口；顶栏角色选择仅用于 Demo 视角切换
- Project 是 Workspace 共享资源：Owner / Admin 可创建且彼此立即可见；Developer 的 Project Scope 只开放查看，项目级 `credential.manage` 再决定能否管理 API Key
- 企业管理新增“角色与权限”页面，分别配置项目可见范围和凭证管理权限；邀请 Developer 时须显式选择项目，凭证写权限默认关闭
- 停用成员前检查其创建、复制或轮换过的有效 Key；可选择先轮换后停用，或保留 Key 并记录高风险确认
- 创建 API Key、查看项目与凭证详情、表达密钥一次性展示；创建、轮换、停用 Key 和成员安全操作使用站内敏感操作确认弹窗
- API Key 直接绑定 Project 并配置最小调用 Scope；创建、轮换、停用会同步列表、详情和站内通知，成员仅作为管理审计主体
- Playground 发起模拟请求并生成 request_id；日志可还原鉴权、配额、推理和计量证据
- 用量可按 Project、API Key、模型和账期核对，不把成员作为生产计费维度
- 服务质量展示合同目标、计算公式、责任排除项、故障响应记录并下钻请求明细
- 费用中心只读展示商务授信余额、已确认订单权益、账期用量、预计费用和 request_id 对账证据
- 在线下单、订单确认、微信/支付宝/企业网银、对公认款、支付结果、充值和自动开通均不进入 V3 客户台
- 原型演示重点收敛为：企业成员与项目权限、项目与 API Key、用量与对账、调用日志与服务质量 Dashboard
- 顶栏数据范围会约束凭证、Playground、用量、日志和服务质量；角色切换会重新解析范围
- 通知可进入业务对象；Key 支持轮换和停用演示；Playground 支持 200/429/504 三类结果
- 企业成员列表支持搜索、角色/状态筛选；成员详情覆盖登录安全、角色与 Project Scope、资源责任和管理审计
- 项目详情串联 API Key、配额、用量趋势和最近 request_id；用量对象详情串联计量规则、对账和费用证据
- 请求日志、服务质量和用量明细均已使用真实图表组件；项目、维度和周期筛选统一作用于指标、图表、列表和详情
- 用量支持“生成中、已生成、部分数据、已更正”，服务质量支持“计算中、可查询、部分数据、口径已更正”状态演示
- 通知中心支持角色/项目过滤、搜索、分类、未读计数、单条/全部已读、消息详情与业务对象跳转；抽屉与完整页面共用状态

## 仍需真实后端

IAM/RBAC 强制鉴权、密钥托管与轮换、网关遥测、不可变计量、真实账单/发票、通知发送、服务事件与合同数据均为后端能力；当前页面使用 mock 数据表达交互和信息口径。

## 本地运行

```bash
pnpm install
pnpm dev
```

默认访问 `http://localhost:4001/`。
