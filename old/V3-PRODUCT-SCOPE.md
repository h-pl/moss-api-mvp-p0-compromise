# Moss API V3 客户控制台范围（V2 客户端基线）

## 决策摘要

范围经 2026-09-01 再次校准：V3 保留 V2 的客户控制台框架和只读订单权益，但移除客户在线下单、订单确认、微信/支付宝/企业网银收银台、对公认款、支付结果、充值及自动开通，同时移除 `Moss Ops · 内部运营`。采购、付款、合同与服务开通统一由商务侧完成，客户台只查询已确认的交付结果。

V3 在 V2 客户端基线上重点加深企业接入治理、Key/调用账号用量归因、费用核查、调用诊断和合同服务质量查询。详细页面和迭代顺序以 `V3-ITERATION-SPEC.md` 为准。

## 合同到页面映射

| 合同/Work C 事实 | V3 页面 | 产品表达 |
|---|---|---|
| MOSS-TTS 1.5-flash、服务期、RPM 500 | 客户概览、订单与权益、配额与限流 | 只读服务事实与当前水位 |
| ¥0.6/万字符；字符、标点、空格、换行均计量 | 用量与对账 | 汇总、每日用量、规则版本、费用组成和请求下钻 |
| 余额低于 ¥3,000 主动通知 | 费用概览 | 余额结构、预警线和预计可用天数 |
| 月度结算单包含调用量、并发包、技术服务天数和费用 | 用量与对账 | 按账期展示结算单及费用明细 |
| 月度可用性 ≥99% | 服务质量 | 合同目标、公式、统计周期和不可用分钟 |
| 5xx/超时计入；维护、客户原因、第三方等排除 | 服务质量 | 责任口径逐类展示并可下钻证据 |
| 重大故障 15 分钟响应、30 分钟初判、2 小时恢复或替代 | 服务质量 | 服务事件时间线和达标判断 |
| 平台监控记录可由客户核查 | 请求日志、服务质量 | request_id、数据来源、规则版本、快照 ID/哈希 |
| 按月依据实际用量签订结算单 | 用量与对账 | 平台只展示结算数据和结算单状态，不提供线上验收动作 |
| 商务已确认的服务交付 | 订单与权益 | 只读展示订单、规则版本、归属项目、配额、服务期和当前状态 |

## 仍需后端支撑

- Workspace/Project 服务端隔离与 RBAC
- Key 密钥服务、一次性展示、轮换与审计
- 网关、推理遥测和计量事件汇聚
- 可复核的统计周期、规则版本和数据来源
- 维护窗口、服务事件和责任归属工作流
- 结算单、发票和通知状态
- 真实结算单文件和导出能力
- 商务订单、付款、认款、充值和履约编排（不进入客户台）

## 原型边界

页面中的指标、request_id、费用、合同主体和状态均为演示数据。原型用于信息展示、查询和产品口径验证，不构成真实服务监控、结算结果或法律验收结论，也不提供线上验收动作。
